# Rule Summary

These rules are about how the variables should look

## Variables Naming Convention

1) Functions use camelCase  
2) Struct use camelCase  
3) Class use PascalCase  
4) Enum use PascalCase  
5) Environmental variables use FULL_CAPS  
6) Normal variable use snake_case  
7) Do not start variable, function, class, or method names with an underscore
